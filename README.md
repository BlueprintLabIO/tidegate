# Tidegate

**The local permissions gate for AI coding agents.**

Stop pasting GitHub tokens into coding agents. Connect once, and Claude, Codex, and Cursor get scoped, audited access through one local gate. They never see the key.

- `site/` — landing page (Astro, SLUICE design system)
- CLI + daemon (Rust) — in progress

v0 is under construction. The landing page ships first; the commands it shows are the shipping interface.
